Star counts are page reads on that date; treat them as relative. Re-check with `prompts/09-review.md` monthly.

## 6. Meta layer
- Official skills repo: anthropics/skills (180k). Spec: agentskills.io/specification. Validate with `skills-ref validate ./skill`.
- Official marketplaces: `claude-plugins-official` (auto-added), `claude-plugins-community`.
- Plugin/marketplace format: `.claude-plugin/marketplace.json` + `plugins/<p>/.claude-plugin/plugin.json` + `skills/ commands/ agents/ hooks/ .mcp.json`. Validate with `claude plugin validate .`. Local dev: `claude --plugin-dir ./plugin`.
- Awesome lists: ComposioHQ/awesome-claude-skills (77k), hesreallyhim/awesome-claude-code (55.6k), VoltAgent/awesome-agent-skills (35.8k), travisvn/awesome-claude-skills (15.4k). Directories: skills.sh, claudemarketplaces.com.
- Personal setups to learn from: brianlovin/claude-config (symlink install + sync script; the model for CLAUDE.md/settings sync), obra/superpowers-marketplace (how to package your own skills as a marketplace).

Two patterns dominate: (a) git repo + install script symlinking into `~/.claude` for personal rules/settings; (b) the repo as a marketplace installed with one command. This toolkit uses (b) for skills and leaves (a) for `~/.claude/settings.json` and a global CLAUDE.md if you want one later.
