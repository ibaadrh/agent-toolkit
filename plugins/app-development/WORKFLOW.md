# App development: the workflow

1. **Research** (`app-feature-extraction`). Pick 3 competitor apps. Screenshots of every flow. APK decompile where legal and useful. Output: feature list ranked by user value, not by how impressive it is.
2. **Scope.** The one job the app must do well in v1. Everything else is a later tag in the backlog.
3. **Structure** (`app-build-structure`). Stack, folders, state, auth, analytics, crash reporting, CI. Set up before the first screen.
4. **Design** (`mobile-ui-taste`). Screens at real device sizes. Platform conventions. Touch targets ≥44 pt.
5. **Build.** Small vertical slices: one flow end to end, tested on device, then the next.
6. **Release** (`app-release-checklist` + `aso-skills`). Signing, screenshots, listing, preflight scan, staged rollout.
7. **Record.** Learnings into the owning skill.
