# Website development: the workflow

1. **Brief.** What the site must do (sell, book, capture leads, inform), for whom, in which languages. Platform decision: static/Next.js, Wix headless (business features needed), or Shopify (commerce). `site.yaml` records it.
2. **Reference.** If there's a site to learn from, run the cloner in recon mode or `site-cloning-brief`. Take structure and rhythm, never copy or assets.
3. **Direction.** `taste-skill` deals three directions; pick one. `impeccable` stays on as the linter.
4. **Build.** Platform skill (`wix-headless-launch` or `shopify-storefront-launch`). Mobile first at 390, then 768, then 1440.
5. **Check.** `impeccable` detector, `ui-craft` a11y audit, `claude-seo` audit, `site-seo-baseline` checklist.
6. **Ship.** Deploy, verify live URLs, submit sitemap, confirm tracking (Pixel/CAPI, GA4) with the digital-marketing toolkit.
7. **Record.** Learnings into the owning skill.
